# 流光 · 流动网页

面向 Agent 与用户协作的整屏网页展示工具：用户提供素材和文字描述，Agent 追问、补充建议并讨论方案，再结合固定模板生成展示；用户可以打开编辑器继续修改，最后打包交付。

提供 **18 个固定版式**，覆盖纯文字、单图与多图、视频、折线图、表格和收尾黑场。每个版式固定内容位，始终不超过 **2 个主标题、2 个小文本、6 张图片**。字号按字数自动适配，页面按页码导航，不需要逐页命名。默认云朵背景、整段轻淡入与静置图片，编辑时按需打开右侧浮层。内容与媒体自动保存，刷新恢复。

开发环境需要 **Node.js 20.19+（20.x）或 22.12+** 与 npm：

```bash
cd web
npm ci
npm run dev
```

预览：**http://127.0.0.1:5173/**。

“打包带走”导出完整 ZIP：网页播放器、当前内容、图片、视频、Mac / Windows 启动脚本与说明。另一台电脑安装 Node 18+ 后，解压并在其中运行：

```bash
node start.mjs
```

打开终端显示的地址即可播放；不需要 npm install、原浏览器数据或外站 CDN。可将 ZIP 交给其他 Agent，按包内说明启动。编辑器的“打开运行包”可将 ZIP 导回继续编辑。

采用现成组件：React、Swiper、Motion、Paper Shaders、Vanta / Three.js、React Bits、shadcn/ui / Radix、Recharts、Dexie、fflate。编辑器与独立播放器共用渲染组件和预设；附带的 Node 服务负责本地静态文件。

根目录原有 `index.html` 保留原样。上一版内容升级时会先留下完整本地备份。

## 生成与分享运行包

启动编辑器，完成内容后点击 **“打包带走”**，即可下载包含当前项目与媒体的 ZIP。运行包在本地生成，不纳入源码仓库。

解压到任意位置，按照包内 `使用说明.txt` 启动即可播放。也可把 ZIP 交给其他 Agent，让它按包内说明启动、修改并重新打包。
