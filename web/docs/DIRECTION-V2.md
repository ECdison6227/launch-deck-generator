# 流动网页方向 · v0.2

用户修正：灵动感优先，网页整屏切换，不沿用三栏 PPT 编辑器。每屏最多 2 个主标题框、2 个小说明框、6 张图片，继续保留视频与既有数据。默认文字自动聚焦出场、圆角卡片自动轻浮并响应指针，背景跨屏持续运行。

设计北极星：进入即是一段有呼吸的网页叙事，编辑只是随手打开的侧面板。

采用单一方向：全窗口 Paper 柔和流动背景，开放文字排版，非对称图片卡片组合，轻量磨砂顶部工具和底部屏幕导航。编辑时打开 Radix Sheet，不保留页面缩略图侧栏、固定画布边框或 PPT 工具条。以 Apple 页面的大留白、清晰字号和精致材质为参考，现成组件拥有运动。

现成组件：Swiper React Creative 负责网页整屏切换；React Bits BlurText 自动文字入场；原样 TiltedCard 的 floating / intro 参数负责卡片出场、轻浮和指针倾斜；Paper MeshGradient 常驻；shadcn Radix 负责所有编辑基础控件。仅编写组合、布局和参数。

可搬运：ZIP 包含当前页面数据、所有引用图片/视频、本地构建的网页播放器与 Node 内置静态启动脚本，无需 npm install，不依赖原浏览器 IndexedDB 或外站 CDN。交付时实际解压，在独立来源运行并验证。

保留 v0.1 数据的迁移备份，不清空已编辑项目。旧表格页作为可选内容保留，不再作为首页的主导表达。

用户进一步收敛：用不同数量文字 + 图片的固定预设保证效果，限制自由度。实现12个版式，固定每个版式的文字位、图片位、比例与留白；不提供手动字号 / 坐标 / 拖拽。只保留配色、内容、字体、文字颜色与现成出场效果。原生字体栈按三种选择回退，字号根据字数配置。新增 window.flowAgent 浏览器调用与运行包内 agent.mjs，均沿用相同预设规则。
