# 流动网页演示

默认进入一段整屏网页叙事：动态色彩贯穿所有场景，文字整段轻淡入，圆角图片默认静置。轻浮和逐字聚焦按屏选用，避免每页都堆叠动效。按需打开编辑浮层，改好即可收起播放。

## 开发与构建

建议 Node 22.12+ 或 24+（满足 Vite 8 要求）。

```bash
cd /Users/cjr/Projects/发布会-ppt-generator/web
npm ci
npm run dev
```

默认地址：**http://127.0.0.1:5173/**；本次固定预览：**http://127.0.0.1:5273/**，便携播放器：**http://127.0.0.1:4188/**。`predev` 自动构建本地便携播放器，再启动 Vite。端口被占用时用 `npm run dev -- --port 5273 --strictPort` 固定到 5273 之类的新端口（本次预览也是 5273）；E2E 默认连 5273。

```bash
npm run typecheck
npm run lint
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

`build` 同时生成编辑器 `dist/` 与独立播放器，播放器原件放在 `public/player/`，并同步到 `dist/player/`。单独更新播放器可运行 `npm run build:player`。播放器的 JS / CSS 均本地打包，运行时不请求 CDN。

## 编辑与播放

- 点击“编辑当前屏”打开右侧浮层；它按内容 / 氛围 / 灵动组织设置。面板覆盖在完整画面上，打开和收起时不压缩画布、不调整字号或图位；背景始终留在网页上，不随编辑或切屏重建。
- 先选版式，再替换内容。18 个固定预设覆盖纯文字、纯单图、一图至六图组合、视频（影像时刻 / 影像主张 / 纯影像整屏）、折线图（趋势图表 / 一页图表）、表格（信息对照）与结尾收束；每个预设固定主标题、小文本和图片位，始终不超过 2 / 2 / 6。文字框数量、字号、位置不提供自由调节。
- 每屏可写一条脚注（页脚小字），结束页用“结尾收束”版式：独立黑色舞台上呈现字幕，停留后完整淡出到黑；编辑时保持文字可见。折线图数据（分类 + 单系列数值）在内容面板直接编辑，渲染用 Recharts 现成折线图。
- 新建时先选择版式；内容面板“换个版式”也可切换。切换前会保存 `before-preset-backup` 备份，再按对应数量保留内容。字号按字数自动适配，适合短标题与简短说明。
- 图片可多选或直接粘贴；达到六张后停止添加。支持独立替换、前移与删除。选择更多图片时只保留容量内的文件。
- 视频使用浏览器原生播放器，支持静音、循环和封面。离开场景前暂停；返回该屏后按播放器按钮重新播放。格式取决于浏览器解码支持。
- “氛围”设置预设布局、网页名、背景样式（流动渐变 / 柔雾颗粒 / 云朵 / 云朵 · 层次 / 纯色）、15 个全局色板（含深色墨夜 / 深海 / 余烬 / 极光，积云 / 夕云云朵背景，以及白纸 / 纯黑 / 冷白纯色）、Hex 颜色、背景速度、暂停、切屏转场（纵深漂移 / 柔和淡入 / 卡片推进）、文字字体与 8 色文字色板 + 任意 Hex。新项目默认使用“云朵 · 积云”。选色板后整页文字色自动匹配；文字 / 图片效果选择后保持编辑面板，点击“重新感受这一屏”主动预览。字体含系统无衬线 / 宋体 / 本地阿里妈妈数黑体，以及 Georgia / Arial / Trebuchet MS / Verdana / Courier New 等常用英文字体栈。Hex 输入回车或离开焦点应用。
- 不适用的设置会禁用：收尾固定黑场、整屏视频覆盖背景时不能修改背景；纯单图 / 纯影像不显示脚注，没有主标题时不能选择文字出场；关闭灵动后不能选择动效或重播。纯色背景仅使用第一个色位，层次云不使用第三个色位；暂停背景后需先恢复才能调节速度。收尾使用浅色文字，深色配色不可选。
- 右上角操作区使用独立实色背景，深色、浅色、云朵和收尾背景下均可读取；独立播放器共用样式，全屏时操作区保持清晰。
- “灵动”默认采用自然淡入（Motion）、静置图片与柔和切屏（Swiper Fade，450ms）；背景缓慢流动；云朵背景最多绘制 230400 像素、每秒最多 30 帧，编辑、收尾及页面不可见时停止逐帧绘制。主标题的 BlurText 聚焦 / 掠入及 TiltedCard 入场 / 轻浮 / 指针倾斜按屏选用；小字只整段淡入，脚注直接呈现。可关闭这一屏灵动，或重新播放当前屏。减少动态效果偏好会自动暂停背景与持续轻浮，并显示清晰静态文字。
- 底部导航只显示页码，不需要逐页起名；＋先挑预设再创建下一屏。编辑浮层底部支持复制、前后排序与确认删除。始终保留至少一屏。
- 方向键、空格和滚轮切换整屏内容；全屏按钮进入原生 Fullscreen API，Esc 退出。切屏由 Swiper 官方现成效果（Creative / Fade / Cards 可选）完成，未实现自有转场引擎。
- 旧表格页迁移时仍保留，信息对照组合中可编辑单元格。

## 保存与旧版兼容

Dexie 数据库 `stage-workbench` 中，项目存于 `projects`，真实媒体 Blob 存于 `media`，没有持久化临时 Blob URL。刷新后重新建立 URL。

v0.1 项目升级前会完整备份到 `projects/v0.1-backup`，再映射到受限场景模型；已有标题、正文、图片与视频继续保留。运行包导入前也先保存 `before-import-backup`。读取失败不会覆盖为初始内容，保存失败保留内存编辑并提供重试。

本地数据跟随浏览器和来源：`127.0.0.1:5173`、`localhost` 和其他端口互相独立。请固定开发地址；要搬到其他来源，使用 ZIP 包。清除站点数据会清除本地项目。

## 打包到其他电脑运行

1. 点击“打包带走”，得到一个 ZIP，包含当前完整项目、所有引用图片 / 视频、本地播放器、许可证及启动说明。
2. 完整解压，目标电脑需有 Node.js 18+。无需源代码、npm install 或原浏览器 IndexedDB。
3. 在解压目录执行 `node start.mjs`。Mac 也有 `start.command`，Windows 有 `start.bat`。
4. 浏览器打开打印的地址，默认 `http://127.0.0.1:4177/`；端口被占用会自动换空闲端口。方向键 / 空格 / 滚轮切屏，F / 按钮进入全屏。
5. 如需继续编辑，回到编辑器，点击“打开运行包”导入 ZIP。

只需一个提供静态文件的本地启动器，没有业务后端、云数据库、账号或网络服务。把 ZIP 交给另一个 Agent 时，让它在解压目录执行 `node start.mjs` 并打开打印的本地地址即可。

播放器要求通过本地 HTTP 打开；不将双击 `file://index.html` 当作可运行方式。解压目录不要只搬 HTML，图片、视频和 assets 需要一并保留。

## Agent 可以调用

浏览器中的 `window.flowAgent` 提供 `inspect()`、`listPresets()`、`apply()`、`addScene()`、`setBackground()`。Agent 可以直接交出内容：`addScene` 接受每屏的大字、小字，以及 base64 data URL 形式的图片和视频，一次调用就能从零搭出一屏，写入 IndexedDB 后刷新仍在。

ZIP 中包含 `agent.mjs` 和配置样本，另一台电脑可运行 `node agent.mjs apply agent-example.json` 修改已有屏，或把本地图片/视频路径写进 JSON 后运行 `node agent.mjs add new-scene.json` 新建一屏——素材会被复制进运行包并登记媒体清单。两者都受同一套固定预设、数量、颜色与效果规则约束。详见 [Agent 调用说明](../docs/AGENT_API.md)。
